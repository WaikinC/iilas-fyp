## Review Focus

1. A zero quantity/no incoming choice versus an empty input: reject unknown, preserve null absence and prevent stale hidden fields (Tasks1/5).
2. A legacy saved request at upgrade/reload: recover original terminal/pending/expired/unknown outcome without a second fit, invented context or erased intent (Tasks4/5).
3. An invalidated source binding during/after inference: reject mixed scientific/model/app versions and refuse late output, including the parcel shared-router binding (Tasks2/4/6).
4. Worker timeout/disconnect/unknown termination: drain the owned native tree before reuse and remain unavailable on ambiguity (Task3).
5. Repeated runs or changed configuration used to overstate accuracy: forbid raw TEST/training access and show study-specific historic metrics, not new scores on old rows (Tasks2/5/6).
