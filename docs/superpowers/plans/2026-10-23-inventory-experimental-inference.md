`Scenario={quantityOnHand,reservedQuantity,reorderLevel,movementFrequency,adjustmentCount,daysSinceReplenishment}` has six strict numeric entries. Quantities/counts integral; all bounds in the spec. `ExperimentInput={operationId,scenario}` uses UUIDv4. `featuresForScenario(scenario)` produces exactly the frozen six snake_case predictors, ordered as the spec. JS canonical sorted JSON binds the validated scenario for idempotency. Cross-language feature hashes must not depend on JSON float spelling: `inventoryAIFeaturePayload(features)` returns protocol plus LF, then one `featureName=hex` line in frozen feature order and a final LF; hex is the16 lowercase hexadecimal digits of each finite IEEE754 binary64 value in big-endian order, normalising either signed zero to+0. Hash those UTF8 bytes with SHA256 for inputSha256. Python uses struct.pack('>d',value).hex(); JS uses DataView.setFloat64 with littleEndianfalse. Neither trusts a caller's digest. Include age1e-7 and-0 interoperability tests so exponent formatting cannot change identity.

Define wire protocol `inventory-synthetic-inference-1.0`, evaluationKind `synthetic-stock-prototype`, origin `simulated-manual`, evaluationOnlytrue, operationally_approvedfalse, independentAccuracyValidatedfalse, acceptanceSha256null, humanReviewRequiredtrue. `Prediction` exact fields: protocol,requestId,inputSha256,features,classOrder,label,probabilities (three-number ordered array),model (`RandomForest`),modelSha256,servingManifestSha256,datasetSha256,developmentSha256,evaluationSha256,processingTimeMs,totalProcessingTimeMs,outOfRange (feature-name array), plus all fixed provenance fields. Timings are finite nonnegative bounded numeric milliseconds, not necessarily integral. Require label to match the saved classifier's argmax tie rule: scikit-learn classes sort Critical Stock Risk/Normal/Reorder Risk; ties use that order, while the displayed probability array retains report class order. Do not invent a display-order tie rule.

Python `/predict/stock-experiment` accepts exact `{protocol,requestId,inputSha256,features}` from the trusted backend; it recomputes the digest and validates all feature relationships/bounds. Health is metadata readiness, not operational acceptance. A missing/incomplete manifest never selects legacy models.py. Backend trusted env names: IILAS_STOCK_API_URL (exact base URL), IILAS_STOCK_API_TOKEN, IILAS_STOCK_MANIFEST_PATH, IILAS_STOCK_MANIFEST_SHA256. Python env names: IILAS_STOCK_SERVICE_TOKEN, IILAS_STOCK_SERVING_MANIFEST, IILAS_STOCK_SERVING_MANIFEST_SHA256. Both roles reference the same manifest bytes/hash, which the backend validates to obtain expected model/data/source identities and development ranges independently of the response. None are VITE variables and none reuse/overwrite parcel settings.

Serving manifest schema `inventory-local-serving-1.0` binds protocol, dataset/development/evaluation relative paths and hashes, RF model relative path/hash/registered parameters/runtime versions, ordered features/classes, development-only min/max ranges, aggregate synthetic metrics and fixed false provenance.
