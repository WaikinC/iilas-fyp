## Review Focus

1. A hostname or stale cached profile changes while a previous SDK/session is alive: reject cross-project access and retain original pending recovery (Tasks 1,5,6).
2. A signed inference response arrives after access loss, product/shipment edits or model rebind: recheck authoritative facts and refuse publication without duplicating business actions (Tasks 2,3).
3. A tunnel changes origin, redirects or replays an expired identity after gateway restart: refuse arbitrary forwarding and refuse starting expired work even with an empty cache (Tasks 2,7).
4. A chain restarts with the same chain ID/address/code: deployment generation and transaction checks prevent historical records appearing reverified or signatures replayed (Task 4).
5. A cloud fixture or cleanup run points at the original project, unknown objects or a partially created resource: abort before writes and preserve unknown resources rather than bulk deleting/restoring (Tasks 7,9,10).

### Shared closed contracts

`DemoEnvironment={schema:'iilas-demo-environment-1.0',mode:'local-emulator'|'cloud-demo',projectId,storageBucket,functionsRegion,webOrigins:string[]}`. Local expected values remain the current project/bucket/region and literal loopback origins/ports; cloud profile must match its independently generated build/runtime allowlist and contain no emulator hosts. Actual Firebase SDK options are a separate ignored input, checked against this profile before SDK initialisation. They are never returned in public environment diagnostics.

`HybridEnvelope={protocol:'iilas-msi-gateway-1.0',projectId,requestId,operation,actor,scope,issuedAtMs,expiresAtMs,operationExpiresAtMs,bindingSha256,payloadJson,payloadSha256}`. requestId is the saved operation's existing nonce/claim identity, not a fresh random value on every retry. Allowed operations are `stock.predict`, `delivery.predict`, `chain.inspect`, `chain.lookup`, `chain.receipt`, `chain.events`. Payloads are operation-specific closed objects encoded as exact UTF-8 JSON; hash exact payloadJson bytes. No caller-selected endpoint, path, token, RPC method or model path. Health uses signed `chain.inspect`/model binding diagnostics through the same admission policy, not an unauthenticated detailed diagnostics endpoint.

Builder constants: gateway binds `127.0.0.1:8010`; one `POST /v1/operation`, JSON bodies≤128KiB, responses≤128KiB; issued time≤5seconds in future, request lifetime≤30seconds and no start after operationExpiresAtMs. Stock/delivery retain their existing 25second request deadlines and 45second lifecycle leases. Chain operations retain the existing bounded 15second IO stage/event window≤256blocks. Cache≤256 unexpired identities for120seconds and≤32MiB, reject admission when full rather than evict active work; one inference per model and at most2 in total, with existing stricter Python guards authoritative. These are transport bounds, not promises of service latency.

Use Node crypto HMAC-SHA256 with a32-byte secret supplied as43-character base64url, separate from Python tokens. Sign canonical envelope bytes using the existing canonical JSON convention and a domain prefix `iilas-msi-request-1.0\n`; response domain `iilas-msi-response-1.0\n`. Reject malformed signatures before timing-safe comparison. `HybridReply={protocol,projectId,requestId,operation,bindingSha256,payloadSha256,status:'ok'|'busy'|'unavailable',resultJson,resultSha256}` is signed and verified against the original request. A replay key binds project/actor/scope/operation/requestId; changed payload/binding/operation deadline under that key refuses. A fresh signed envelope can retrieve the same retained result; cache loss never allows starting after the original operation deadline. Durable Firebase receipts/final checks provide business recovery; do not claim exactly-once inference across MSI crashes.

`CloudModelBinding={schema:'iilas-cloud-model-binding-1.0',stock:{expected,metrics,provenance},delivery:{expected,metrics,provenance},sourceManifestSha256}`. `expected` retains the existing validator fields modelSha256/servingManifestSha256/datasetSha256/developmentSha256/evaluationSha256/ranges. Produce only from a successfully verified local serving configuration, with exact feature/class order and frozen disclosure checks. Bind this digest in the gateway and cloud adapter; no runtime acceptance of a different model just because the gateway reports it.
