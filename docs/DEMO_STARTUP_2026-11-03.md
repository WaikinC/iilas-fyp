# Starting the supervisor demo

1. On MSI, double-click **Start IILAS Demo** on the Desktop.
2. Wait for **Ready** beside Blockchain, Inventory AI, Delivery AI, Application backend and Website connection, then **SERVICES CONNECTED**.
3. Open [IILAS](https://fyp-inventory-and-logistics.web.app/) and sign in. Your original laptop can use the same website while MSI stays online.
4. Keep MSI awake, plugged in and online. Closing the launcher after the checks finish leaves the services running. No separate manual AI/backend startup is needed.
5. For new blockchain registrations, unlock MetaMask in normal MSI Chrome and select the imported local test account on IILAS Local Demo, chain31337. Review each transaction yourself. Ordinary stock and logistics operations do not require wallet signing.
